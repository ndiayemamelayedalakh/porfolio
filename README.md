## 📁 Structure du projet

```
portfolio/
├── index.html          # Page d'accueil (à propos, compétences, formation, expériences, projets, contact)
├── style.css           # Feuille de style partagée par toutes les pages
├── script.js           # Animations et interactions (scroll reveal)
├── sae1-01.html        # Reporting à partir d'un SGBD
├── sae1-02.html        # Mise en forme et exploration d'un jeu de données (JO)
├── sae1-03.html        # Écriture et lecture de fichiers avec Python (Prix Nobel)
├── sae1-04.html        # Analyse médicale — base de données relationnelle
├── sae1-05.html        # Accidents corporels en Normandie
├── sae1-06.html        # Mise en œuvre d'une enquête (médias & lycéens)
├── sae1-07.html        # Reporting & datavisualisation (Power BI)
├── Images/             # Illustrations et graphiques
├── Raapports/          # Rapports PDF téléchargeables
└── Scripts/            # Scripts Python et R affichés dans les pages
```

## 🚀 Lancer le projet en local

Aucune installation requise. Il suffit de cloner le dépôt et d'ouvrir `index.html` dans un navigateur :

```bash
git clone https://github.com/ndiayemamelayedalakh/portfolio.git
cd portfolio
# Ouvrir index.html dans votre navigateur
```
