Analyse Médicale : Création de Base de Données Relationnelle à partir de Données de Santé Synthétiques

Présentation du projet

Ce projet consistait à créer une base de données relationnelle à partir de données de santé synthétiques. Le but était de simuler le travail d’un gestionnaire de données médicales : nettoyer et préparer les données avec Python (Pandas, NumPy), concevoir un MCD et un MLD, implémenter la base dans MySQL et analyser les résultats, tout en garantissant l’intégrité et la cohérence des données.

Organisation et démarche

Le projet consistait à nettoyer et préparer le fichier jeu_donnees_sante.csv pour l’insertion dans une base de données relationnelle.
Les principales étapes réalisées étaient les suivantes :

  • Chargement des données dans un DataFrame Pandas et vérification des types de données (dates, numériques).
  • Gestion des valeurs manquantes : imputation de la valeur la plus fréquente pour Insurance Provider et de la valeur la moins fréquente pour Medication.
  • Correction des incohérences et erreurs typographiques : uniformisation des noms des patients et médecins, standardisation des conditions médicales, nettoyage des noms d’hôpitaux.
  • Détection et suppression des doublons si leur taux était inférieur à 10%.
  • Vérification des valeurs aberrantes et correction si nécessaire (ex. valeurs négatives dans Billing Amount).
  • Utilisation éventuelle de fonctions auxiliaires pour organiser et automatiser le nettoyage des données.

            def nettoyer_et_inverser(nom):
            """
            Nettoie une chaîne de caractères représentant un nom, supprime les mots non pertinents,
            capitalise chaque mot, puis inverse l'ordre pour afficher le nom de famille en premier.

            
            Étapes :
            - Supprime les points et les espaces superflus
            - Élimine les mots présents dans la liste `a_supprimer` (comparés en minuscules)
            - Capitalise chaque mot
            - Inverse l'ordre : "Prénom Nom" devient "Nom Prénom"
            - Si un seul mot est présent, il est retourné tel quel
            - Si aucun mot pertinent n'est trouvé, retourne np.nan

            Paramètres :
            ----------
            nom : str
                Chaîne de caractères à nettoyer et réorganiser.

            Retour :
            -------
            str ou np.nan
                Nom réorganisé sous la forme "Nom Prénom", ou np.nan si la chaîne est vide ou non pertinente.
            """


            nom = nom.replace('.', '')  # Enlève les points
            nom = ' '.join(nom.split())  # Nettoie les espaces
            mots = nom.strip().split()
            
            # Supprimer les mots à exclure (en comparant en minuscules)
            mots = [m for m in mots if m.lower() not in a_supprimer]

            # Capitaliser proprement chaque mot
            mots = [m.capitalize() for m in mots]

            if len(mots) >= 2:
                prenom = ' '.join(mots[:-1])
                nom_famille = mots[-1]
                return nom_famille + " " + prenom
            elif len(mots) == 1:
                return mots[0]
            else:
                return np.nan
