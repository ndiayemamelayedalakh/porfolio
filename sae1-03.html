Présentation du projet

Ce projet consiste à analyser les données sur les lauréats des Prix Nobel à l'aide du langage Python. À partir du fichier prix_nobel_donnees.csv, nous avons identifié les lauréats, leurs contributions et les contextes d'attribution afin de dégager des tendances et statistiques pertinentes. Le projet comprend l'utilisation de la bibliothèque Openpyxl pour le nettoyage, la manipulation et l'analyse des données.

Méthodologie

Organisation et démarche

Le projet a été réalisé en groupe de quatre, avec un suivi quotidien. La démarche a commencé par un nettoyage rigoureux des données : uniformisation des valeurs manquantes avec des mentions comme N/A ou Inconnue.

Une fois le jeu de données fiabilisé, plusieurs fonctions Python ont permis de produire des statistiques clés : répartition hommes-femmes, âge minimal et maximal des lauréats, classement des pays les plus récompensés.

Exemple de script Python

Cette fonction illustre l'enrichissement du jeu de données par calcul d'âge :

script_nobel.py 
def ajouter_col_age_au_prix(donnees):
    """
    Ajoute une colonne "age_au_prix" au jeu de données,
    indiquant l'âge du lauréat au moment de l'obtention du prix Nobel.
    Si la date de naissance est inconnue, la valeur est fixée à None.
    """
    for laureat in donnees:
        if laureat["birth_date"] != "Inconnue":
            age = laureat["year"] - laureat["birth_date"].year
            laureat['age_au_prix'] = age
        else:
            laureat['age_au_prix'] = None
