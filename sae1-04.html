Contexte

Présentation du projet

Ce projet consistait à créer une base de données relationnelle à partir de données de santé synthétiques. Le but était de simuler le travail d'un gestionnaire de données médicales : nettoyer et préparer les données avec Python (Pandas, NumPy), concevoir un MCD et un MLD, implémenter la base dans MySQL et analyser les résultats, tout en garantissant l'intégrité et la cohérence des données.

Méthodologie

Organisation et démarche

Le projet consistait à nettoyer et préparer le fichier jeu_donnees_sante.csv pour l'insertion dans une base de données relationnelle.

01
Chargement Chargement dans un DataFrame Pandas et vérification des types de données (dates, numériques).
02
Valeurs manquantes Imputation de la valeur la plus fréquente pour Insurance Provider et la moins fréquente pour Medication.
03
Nettoyage Uniformisation des noms de patients et médecins, standardisation des conditions médicales et des noms d'hôpitaux.
04
Doublons & aberrations Détection et suppression des doublons si leur taux était inférieur à 10%, correction des valeurs aberrantes.

def nettoyer_et_inverser(nom):
    """
    Nettoie une chaîne représentant un nom, supprime les mots
    non pertinents, capitalise chaque mot, puis inverse l'ordre
    pour afficher le nom de famille en premier.
    """
    nom = nom.replace('.', '')
    nom = ' '.join(nom.split())
    mots = nom.strip().split()

    # Supprimer les mots à exclure
    mots = [m for m in mots if m.lower() not in a_supprimer]
    mots = [m.capitalize() for m in mots]

    if len(mots) >= 2:
        prenom = ' '.join(mots[:-1])
        nom_famille = mots[-1]
        return nom_famille + " " + prenom

        return mots[0]
